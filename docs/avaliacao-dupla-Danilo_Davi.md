# Avaliação entre Pares do Projeto

-> Link do Repositório: https://github.com/Danilolsr1/Projeto-Intregador-3
-> Link do site no Github Pages: https://danilolsr1.github.io/Projeto-Intregador-3

O site criado é um site para um mercado da região, um negócio regional que seria muito beneficiado caso possuísse um site. O site em questão é bem simples, mais para apresentação do negócio. Na reforulação do site original a dupla priorizou uma limpeza na interface já que o site original é extremamente poluído visualmente. As funcionalidades do site estão funcionando sem problemas. A experiência do usuário foi razoável, as cores escolhidas mantém fiel ao site original, mas estão um tanto saturadas, fora isso nada demais. A responsividade do site não funciona corretamente, é uma boa sugestão arrumar esse problema. Em questão de código o site é satisfatório, código limpo, simples e de fácil manutenção, ótimo para adicionar novas features no futuro. Mas foram encontrados alguns arquivos com erros graves em seus tipos, arquivos terminados em .html.txt que precisam ter essa terminação corrigida o quanto antes. Fora isso tudo, é um bom trabalho acadêmico que tem muito potencial para crescer e evoluir, especialmente se corrigirem os erros percebidos.

-> A avaliação era para ser feita com base numa Rubrica, da Parte 3 em específico, que estaria em anexo na atividade em questão. No entanto não estava e tivemos que avaliar sem seguir a tal Rubrica.
